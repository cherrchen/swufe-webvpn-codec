## 主窗口（720×560，零滚动）

信息层级不变（状态 → 主操作 → 配置 → 诊断），但**长内容不再出现在主窗口**：候选应用列表进捕获窗口、日志进日志窗口、allowlist 编辑进 allowlist 窗口。

```text
┌───────────────────────────────────────────────────────────────┐
│ SWUFE WebVPN Bridge                          ● 已登录         │  状态条（文字状态名 + 图标，不靠颜色）
├───────────────────────────────────────────────────────────────┤
│ [ 重新登录 ]                         桥接  ( ●──── )          │  主操作（唯一必须点击的入口）
├───────────────────────────────────────────────────────────────┤
│ 捕获方式                                                      │
│ (•) 系统代理（全部流量）   ( ) 指定应用                        │  一级选择（互斥，REQ-003 / ADR-0006）
│ 进程捕获：已启用（2 个应用）           [ 选择应用… ]          │  状态行 + 入口（→ 捕获窗口）
├───────────────────────────────────────────────────────────────┤
│ Allowlist   3 个主机（含 *.swufe.edu.cn）          [ 管理… ]   │  摘要 + 入口（→ Allowlist 窗口）
├───────────────────────────────────────────────────────────────┤
│ 证书  已安装并被系统信任                                      │
│ [ 安装本机 CA ]   [ 卸载本机 CA ]                             │  REQ-010（安装前弹风险提示）
├───────────────────────────────────────────────────────────────┤
│ 诊断                                                          │
│ 系统代理：由本 App 指向 127.0.0.1:8080                        │  只读一行（替代既有「高级」折叠区）
│ 调试日志  ( ●──── )                                           │  开关（→ 日志窗口；关闭即关窗并清空）
├───────────────────────────────────────────────────────────────┤
│ 已添加 portal.swufe.edu.cn。                                  │  消息行（role=status, aria-live=polite）
└───────────────────────────────────────────────────────────────┘
```

约束（[spec.md](spec.md) SC2-001 / SC2-002 / SNFR-001）：

- 根容器 `height: 100vh; overflow: hidden`；区块用固定行高与紧凑间距（AntD `componentSize="small"` + token 调整），任何区块都不得成为可滚动容器。
- 不设折叠区：「高级」区取消折叠，改为常驻的「诊断」两行（系统代理状态 + 调试日志开关），避免折叠展开改变窗口高度。
- 窗口尺寸不可由用户拖拽改变；只随内容缩放系数（`zoomFactor`）按比例变化（见 [design.md](design.md) §2）。
- 溢出（内容缩放，EC2-009）的处置是：先随内容缩放系数放大窗口（clamp 到工作区），仍装不下才把内容外移到二级窗口——**不加滚动条**。

实测口径（TC-J01，CDP 在真实窗口执行）：

1. 内容缩放系数 1.0 时：`document.scrollingElement.scrollHeight ≤ document.scrollingElement.clientHeight`；
2. 文档内无元素满足「`scrollHeight > clientHeight + 1` 且 `overflow-y` 为 `auto`/`scroll`」；
3. 窗口外框尺寸 ≈ 720×560 × zoomFactor（clamp 到 `workArea - 80/−120`），且内容缩放系数 1.25 / 1.5 时窗口随比例增大；
4. 在 zoom 1.0 / 1.25 / 1.5 三档下分别执行 1、2。

## 捕获窗口（560×480）

入口：主窗口 [选择应用…]（一次点击；重复点击聚焦同一窗口）。

```text
┌───────────────────────────────────────────────────────┐
│ 进程捕获 — 应用选择                                   │
├───────────────────────────────────────────────────────┤
│ 状态：已启用（2 个应用）                              │
│ 当前捕获方式：指定应用                                │  当方式为系统代理时：显示「当前捕获方式为系统代理，进程捕获未启用」
├───────────────────────────────────────────────────────┤
│ [筛选应用名…]                    [ 刷新列表 ]         │
├───────────────────────────────────────────────────────┤
│ ☑ Google Chrome        /Applications/Google Chrome…   │  一行一个应用（主进程与 Helper 归并为一行）
│ ☑ curl                 /usr/bin/curl                  │
│ ☐ Safari               /Applications/Safari.app       │
│ …（内部滚动）                                          │
├───────────────────────────────────────────────────────┤
│ 已选 2 / 32                                           │
└───────────────────────────────────────────────────────┘
```

失败态（仅进程捕获失败时出现，替换状态行下方区域）：

```text
│ 启用失败 — <原因>                                     │
│ 首次启用时 macOS 会安装并激活 mitmproxy 的网络扩展：  │
│ 请在系统设置 → 通用 → 登录项与扩展（或弹出的授权提    │
│ 示）中允许。未在 5 秒内确认会导致启用失败，授权后点   │
│ 「重试」。                            [ 重试 ]         │
```

行为：勾选/取消立即下发并落盘（无需重启、无需重开桥，REQ-003）；枚举失败或列表为空时显示空态与原因（EC2-006）；未登录时允许打开，勾选可保存但不生效（EC2-010）。

## 日志窗口（720×420）

入口：主窗口「调试日志」开关打开时自动打开；重复点开关不新开窗口（开关关闭时窗口自动关闭并清空，EC2-002）。

```text
┌───────────────────────────────────────────────────────────────┐
│ 调试日志            最近 200 条，最新在前          [ 清空 ]   │
├───────────────────────────────────────────────────────────────┤
│ 时间        │ 域名                      │ 结果                 │
├─────────────┼───────────────────────────┼──────────────────────┤
│ 12:01:03    │ jwxt.swufe.edu.cn         │ 已改写               │
│ 12:01:03    │ example.com               │ 未改写（非 allowlist）│
│ …（内部滚动）                                                 │
└───────────────────────────────────────────────────────────────┘
```

空态：`尚无日志：开启调试日志并产生流量后在此显示。`
记录内容不变（REQ-009 / NFR-003）：仅时间、域名、结果；不含正文、请求体与 Cookie。窗口重开时从 Main 环形缓冲恢复（≤200 条，AC2-006）。

## Allowlist 窗口（480×400）

入口：主窗口 [管理…]（主窗口只保留摘要）。

```text
┌───────────────────────────────────────────────────────┐
│ Allowlist                                             │
├───────────────────────────────────────────────────────┤
│ [ 输入主机名，如 portal.swufe.edu.cn ]   [ 添加 ]     │
│ 主机名不合法：<输入>                                  │  非法时内联错误，不写入
├───────────────────────────────────────────────────────┤
│ jwxt.swufe.edu.cn                              [ 删 ] │
│ portal.swufe.edu.cn                            [ 删 ] │
│ …（内部滚动）                                          │
├───────────────────────────────────────────────────────┤
│ ☐ 启用 *.swufe.edu.cn（含 apex swufe.edu.cn）          │
└───────────────────────────────────────────────────────┘
```

行为：增删与通配勾选立即生效并在重启后保留（REQ-005 / TC-J07）；默认值仍为 `{"hosts":["jwxt.swufe.edu.cn"],"includeSwufeWildcard":false}`；`webvpn.swufe.edu.cn` / `authserver.swufe.edu.cn` 的硬编码排除不因界面变化而改变。

## 状态与文案

状态条与桥状态机一致（沿用既有语义，仅呈现方式改为 AntD 组件）：

| 状态 | 状态条 | 桥接开关 | 备注 |
| ---- | ------ | -------- | ---- |
| 未登录 | 灰色「未登录」 | 禁用 | |
| 已登录未开桥 | 蓝色「已登录」 | 可开 | |
| 桥接中 | 绿色「桥接中」 | 可关 | 系统代理方式，或指定应用但捕获未生效 |
| 桥接中（进程捕获） | 绿色「桥接中（进程捕获）」 | 可关 | 指定应用且 sidecar 已报告 `enabled: true` |
| 错误 | 红色 + 原因文字 | 视情况 | 例如代理冲突、`CA_MISSING` |
| 过期处理中 | 橙色 | 强制关 | 模态：[去登录] |

文案来源：既有错误文案常量为唯一来源（`apps/desktop/src/main/constants.ts` 的 `ERROR_MESSAGES`，与 [docs/ui-ux/main-window.md](../../docs/ui-ux/main-window.md) 的文案表一致），渲染层不复制文本、只消费 Main 返回的错误码与消息。本次新增/固定的文案：

| 位置 | 文案 |
| ---- | ---- |
| 捕获窗口状态行（系统代理方式） | 当前捕获方式为系统代理，进程捕获未启用。 |
| 捕获窗口空态 | 暂无候选应用：请点「刷新列表」重试。 |
| 日志窗口空态 | 尚无日志：开启调试日志并产生流量后在此显示。 |
| Allowlist 窗口非法主机 | 主机名不合法：<输入>（与既有界面文案一致） |
| 主窗口 allowlist 摘要 | `N 个主机` / `N 个主机（含 *.swufe.edu.cn）` |
| 窗口加载失败（错误边界） | 界面加载失败：<原因>。可点「重新加载窗口」重试。 |
| 窗口标题 | `SWUFE WebVPN Bridge`（主）/ `进程捕获 — 应用选择` / `调试日志` / `Allowlist` |

CA 风险提示、代理冲突、会话过期三条模态的正文与既有文案一致（安装 CA 前必须展示风险提示，NFR-005）。

## 可访问性

- 键盘：全部交互控件可 Tab 聚焦并操作（AntD 控件自带 `focusable` 与键盘语义）；危险操作（安装/卸载 CA）不依赖悬停可见。
- 状态表达：状态条同时给出文字状态名；错误为「红色 + 文字 + 错误码」；进程捕获失败给出「启用失败 — <原因>」文字而非仅图标。
- 窗口语义：每个窗口有稳定标题（见上表），窗口标题即用户在多窗口环境中的定位手段。
- 语言：全部窗口文案中文（`ConfigProvider` 的 `zh_CN` locale，NFR-007）。
- 主题：亮色默认（暗色为 SNG-002 非目标）。
