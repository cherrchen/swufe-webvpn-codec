# 二级窗口（Secondary Windows）

> Status: Draft ｜ Owner: cherrchen ｜ Last Reviewed: 2026-09-23

## 目标

- 用户目标：把三类**长内容**（进程捕获的应用选择、调试日志、Allowlist 编辑）从主窗口移出，使主窗口在固定小尺寸下一屏承载全部高频内容且零滚动；二级窗口打开时主窗口仍可操作。
- 关联需求：REQ-003（流量接管与候选应用）、REQ-005（Allowlist 路由）、REQ-009（可观测性与调试日志）、REQ-012（多窗口界面结构）、NFR-003、NFR-007。
- 关联 Spec：[specs/002-desktop-ui-multiwindow/](../../specs/002-desktop-ui-multiwindow/spec.md)；主窗口见 [main-window.md](main-window.md)。

## 共同约定

| 项 | 约定 |
| --- | ---- |
| 模态 | **非模态**：不设置父窗口，不阻塞主窗口；用户可同时与主窗口和二级窗口交互 |
| 实例 | 每类最多一个：重复触达入口（如再次点 [选择应用…]）只聚焦并前置已有窗口，不新开 |
| 生命周期 | 由主窗口的 [选择应用…] / 调试日志开关 / [管理…] 打开；主窗口关闭即退出应用，二级窗口随进程退出；单个二级窗口被关闭只销毁自身，不改变任何持久化状态 |
| 状态来源 | 状态权威仍在 Electron Main：窗口挂载时拉取一次初始状态，随后只跟随 Main 的广播事件（状态、日志、会话过期）与自身操作的返回值 |
| 隔离 | 与主窗口同一隔离级别：`contextIsolation: true` + `sandbox: true` + 无 Node 集成，共用同一个 preload |
| 滚动 | 只有窗口内的列表/表格区域滚动，文档级不滚动 |
| 文案 | 中文优先（Ant Design `zh_CN` locale） |

## 捕获窗口

尺寸 560×480（可缩放，最小 = 默认）。入口：主窗口 [选择应用…]。

```text
┌───────────────────────────────────────────────────────┐
│ 进程捕获：已启用（2 个应用）                          │  四种状态行同主窗口
│ 当前捕获方式：指定应用                                │  系统代理时：当前捕获方式为系统代理，进程捕获未启用。
│ 系统代理：全部流量经本桥；指定应用：只有所选应用的流  │  常驻说明行（说明两种方式互斥与切换影响）
│ 量经本桥，本 App 不设置系统代理（切换时会撤销本 App   │
│ 设置过的系统代理）。                                  │
├───────────────────────────────────────────────────────┤
│ [筛选应用名…]                          [ 刷新列表 ]   │
├───────────────────────────────────────────────────────┤
│ ☑ Google Chrome          （已选中的排在最前）         │
│ ☐ curl                                                │  一行一个应用（主进程与 Helper 归并为一行）
│ ☐ Safari                                              │
│ …（列表内部滚动）                                     │
├───────────────────────────────────────────────────────┤
│ 已选 1 / 32                                           │  选择上限 32（与 Main 的校验一致）
└───────────────────────────────────────────────────────┘
```

失败态（仅进程捕获失败时，替换状态行下方区域）：

```text
│ 进程捕获：启用失败 — <原因>
│ 首次启用时 macOS 会安装并激活 mitmproxy 的网络扩展：请在系统
│ 设置 → 通用 → 登录项与扩展（或弹出的授权提示）中允许。未在 5 秒内
│ 确认会导致启用失败，授权后点「重试」。          [ 重试 ]
```

| 项 | 约定 |
| --- | ---- |
| 列表内容 | 已选中的 pattern 始终在列表中（按保存顺序排在最前），其后为命中筛选的未选候选；候选名缺失时显示 `<pattern>（当前未运行）` |
| 勾选/取消 | 立即下发并落盘（`setCaptureProcesses` 整体覆盖当前选择），无需重启、无需重开桥；失败时显示原因并回滚到 Main 的当前值 |
| 筛选 | 按应用名（不区分大小写）过滤未选候选；已选中的行不受筛选影响（否则无法取消勾选） |
| [刷新列表] | 重新枚举候选应用；枚举失败或为空时显示空态 |
| 空态 | 候选为空：`暂无候选应用：请点「刷新列表」重试。`；筛选无结果：`没有匹配的应用。` |
| 边界 | 未登录时允许打开（勾选可保存但不生效，开桥仍由 `NOT_LOGGED_IN` 约束）；切回「系统代理」后窗口保留，内容显示「当前捕获方式为系统代理，进程捕获未启用」，勾选仍可查看与修改（落盘、不生效） |
| 上限 | 已选数量 ≤ 32；达到上限后 Main 拒绝新增并返回错误（渲染层不做业务判定） |

## 日志窗口

尺寸 720×420（可缩放，最小 = 默认）。入口：主窗口「调试日志」开关打开时自动打开；关闭开关时窗口自动关闭且缓冲清空。

```text
┌───────────────────────────────────────────────────────────────┐
│ 调试日志        最近 200 条，最新在前（当前 3 条）  [ 清空 ]  │
├───────────────────────────────────────────────────────────────┤
│ 时间        │ 域名                      │ 结果                 │
├─────────────┼───────────────────────────┼──────────────────────┤
│ 12:01:03    │ jwxt.swufe.edu.cn         │ 已改写               │
│ 12:01:03    │ example.com               │ 直连                 │
│ …（表格内部滚动）                                             │
└───────────────────────────────────────────────────────────────┘
```

| 项 | 约定 |
| --- | ---- |
| 记录键集合 | 固定为 `ts` / `host` / `rewritten` / `direction` / `detail`；不含请求/响应正文与 Cookie（NFR-003） |
| 结果列 | `已改写`（请求方向、已改写）/ `响应改写`（响应方向、已改写）/ `直连`（未改写）；`detail` 存在时追加 `（<detail>）` |
| 排序与容量 | 最新在前；最多 200 条，超出丢弃最旧（缓冲在 Main，渲染层只显示） |
| 历史恢复 | 窗口关闭再打开（开关仍为开）时，从 Main 的环形缓冲恢复最近记录，不因窗口关闭而丢失 |
| [清空] | 清空 Main 环形缓冲并清空列表（清空后窗口重开仍为空） |
| 空态 | `尚无日志：开启调试日志并产生流量后在此显示。` |
| 渲染节流 | 高频推流的记录按合并窗口渲染（常规 100ms；窗口已满 200 行且到达速率 > 50 条/秒 时 250ms），避免满速流量下阻塞交互 |
| 边界 | 调试日志默认关闭；日志缓冲仅存内存，不落盘 |

## Allowlist 窗口

尺寸 480×400（可缩放，最小 = 默认）。入口：主窗口 [管理…]（主窗口只保留摘要）。

```text
┌───────────────────────────────────────────────────────┐
│ Allowlist                                             │
├───────────────────────────────────────────────────────┤
│ [ 输入主机名，如 portal.swufe.edu.cn ]   [ 添加 ]     │
│ 已添加 portal.swufe.edu.cn。                          │  成功/失败提示（非法时内联错误，不写入）
├───────────────────────────────────────────────────────┤
│ jwxt.swufe.edu.cn                              [ 删除 ]│
│ portal.swufe.edu.cn                            [ 删除 ]│
│ …（列表内部滚动）                                     │
├───────────────────────────────────────────────────────┤
│ ☐ 启用 *.swufe.edu.cn（含 apex swufe.edu.cn）         │
└───────────────────────────────────────────────────────┘
```

| 项 | 约定 |
| --- | ---- |
| 添加 | 输入非空且结构合法（域名标签由字母数字与 `-` 组成、至少两个标签）才提交；成功后清空输入并提示 `已添加 <host>。`，主窗口摘要随之刷新 |
| 校验 | 空输入 → `请输入主机名。`；结构不合法 → `主机名不合法：<输入>`；两者都只做内联提示、**不写入**。最终校验仍在 Main（大小写归一、去尾点、非法字符与长度检查），Main 的拒绝原因显示在同一内联位置 |
| 删除 | 每行 [删除]（`aria-label` 为 `删除 <host>`）→ 保存剩余主机并提示 `已删除 <host>。` |
| 通配 | `启用 *.swufe.edu.cn（含 apex swufe.edu.cn）` 勾选即保存；默认关闭 |
| 默认值 | `{"hosts":["jwxt.swufe.edu.cn"],"includeSwufeWildcard":false}`；`webvpn.swufe.edu.cn` / `authserver.swufe.edu.cn` 的硬编码排除不因界面变化而改变 |
| 持久化 | 增删与通配勾选立即生效（写入 `<userData>/config.json`）并在重启后保留 |
| 空态 | 无主机时显示「（空：所有流量直连）」；开桥要求至少一个主机或勾选通配（否则错误码 `ALLOWLIST_EMPTY`） |

## 可访问性

- 键盘：全部交互控件可 Tab 聚焦并操作（复选框、输入框、按钮均为 Ant Design 控件，具备键盘语义）。
- 状态表达：计数、状态行与错误均为文字（如「启用失败 — <原因>」、「已选 1 / 32」），不依赖颜色。
- 窗口标题：`进程捕获 — 应用选择` / `调试日志` / `Allowlist`，是用户在多窗口环境中的定位手段。
- 文案与本地化：全部中文（NFR-007）；主题为亮色默认。
