# 测试计划 — SWUFE WebVPN Bridge Phase 1

## 1. 目的

验证第一期需求：在 macOS / Windows 上，用户登录官方 WebVPN 后，本机浏览器可经本地桥访问并操作教务站点；系统代理与进程捕获、CA、会话过期、代理冲突等行为符合规格。

## 2. 范围

### 在范围内

- WrdCodec 编解码正确性
- Session / 防环
- Allowlist 匹配（精确 + 可选通配）
- 系统代理设置/清除与冲突拒绝
- CA 安装/卸载（能测则测；CI 可降级）
- mitm 请求改写与关键响应改写
- Electron 主流程 UI
- 教务浏览器验收（手工为主）

### 不在范围内（Phase 1）

- TUN / sing-box
- Linux
- 与 Clash 链式共存
- 性能压测、模糊测试全量

## 3. 策略

| 层级 | 方法 | 环境 |
|---|---|---|
| L0 单元 | codec 向量、allowlist 函数 | CI |
| L1 组件 | addon 对录制流量/假上游 | 本地 |
| L2 集成 | mitmdump + curl 经代理访问假 WebVPN | 本地 |
| L3 系统 | 真机 + 真实 WebVPN + 浏览器教务 | 手工（需账号） |
| 回归 | L0 每次 PR；L3 发版前 | |

真实账号测试仅在授权设备进行；日志遵循「不记正文」。

## 4. 入口准则

- 需求规格与接口/数据模型已评审
- codec 自检通过
- 可构建 Electron 开发版与启动 mitm sidecar

## 5. 出口准则

- 所有 P0 用例通过
- P1 用例无未决阻断缺陷
- 教务浏览器验收在至少一侧桌面 OS 通过（目标两侧都过）
- 已知问题列表已记录

## 6. 优先级

- **P0**：阻塞验收（登录、开桥、教务浏览、过期停桥、代理冲突、CA 基本可用）
- **P1**：allowlist 编辑、通配、调试日志、进程捕获
- **P2**：文案、托盘、边界 UI

## 7. 环境与工具

- macOS、Windows 各一测试机
- Chrome/Edge 各一
- mitmproxy、curl
- 测试账号：测试者自有西财账号（不写入仓库）

## 8. 风险

| 风险 | 对策 |
|---|---|
| 教务页面结构变化 | 验收以「可操作关键路径」为主，不绑定 DOM |
| CAS/MFA 人工步骤 | L3 手工；自动化只到 Cookie 注入后 |
| CA 信任需管理员权限 | 文档化；用例分「已信任」前提 |
