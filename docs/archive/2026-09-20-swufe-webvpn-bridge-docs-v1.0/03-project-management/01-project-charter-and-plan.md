# 项目管理 — 项目章程与计划（Phase 1）

## 1. 项目章程

| 项 | 内容 |
|---|---|
| 项目名称 | SWUFE WebVPN Bridge Phase 1 |
| 目标 | 交付 macOS/Windows Electron 应用，使本机浏览器经官方 WebVPN 会话访问 allowlist 内 HTTP/HTTPS 资源（验收：教务可操作） |
| 发起诉求 | 学校仅提供 WebVPN；需本地桥而非自研完整 VPN 内核 |
| 成功标准 | 需求规格验收清单完成；P0 测试通过 |
| 范围边界 | 见 PRD 非目标；不上 TUN；不与 Clash 共存 |
| 主要干系人 | 开发者本人（产品+研发）；未来开源用户（间接） |
| 约束 | 不存密码；须装本机 CA；须遵守学校账号使用规范 |
| 假设 | WRD 默认密钥短期内有效；mitmproxy 可嵌入或随附 |

## 2. 阶段计划

| 阶段 | 产出 | 依赖 |
|---|---|---|
| M0 预研 | Codec 验证、需求规格、本文档包 | 已完成 |
| M1 桥核心 | mitm WRD addon、Cookie 注入、单测/集成测 | M0 |
| M2 桌面编排 | Electron 壳、系统代理、CA、冲突检测、过期停桥 | M1 |
| M3 体验打磨 | Allowlist UI、调试日志、进程捕获、文案 | M2 |
| M4 验收 | macOS+Windows 教务浏览器验收、缺陷收敛 | M3 |
| M5 可选 | 开源清理、README、后续 TUN 设计备忘 | M4 |

## 3. 角色（轻量）

第一期默认同一人兼任：产品、研发、测试。开源前增加：文档审阅、安全自查清单。

## 4. 沟通与变更

- 需求变更：更新 PRD/数据模型版本号，同步测试用例
- 密钥/门户变更：优先改 Session/Codec 配置，不改整体架构

## 5. 合规与伦理备注

- 仅供有权使用 WebVPN 的用户访问授权资源
- 文档与开源说明中明确：本工具模拟浏览器经 WebVPN 访问，不提供未授权穿透
- HTTPS 解密仅限本机用户同意安装 CA 的设备
