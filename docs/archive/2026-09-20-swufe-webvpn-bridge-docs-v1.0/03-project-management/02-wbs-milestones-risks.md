# WBS、里程碑与风险管理

## 1. WBS（工作分解）

```text
1. 文档与治理
   1.1 需求/设计/测试/项目文档（本包）
   1.2 开源许可与安全说明（后置）
2. WRD 与核心库
   2.1 Codec 库固化与向量测试
   2.2 Allowlist 匹配库
3. Bridge Sidecar
   3.1 mitm 工程骨架
   3.2 请求改写 addon
   3.3 响应反向改写
   3.4 Cookie/配置热更新
   3.5 控制/健康检查（可选）
4. Electron 应用
   4.1 工程脚手架
   4.2 登录 WebView + Session Broker
   4.3 Proxy Orchestrator（系统代理）
   4.4 Cert Manager
   4.5 Allowlist / 开关 / 状态 UI
   4.6 进程捕获 UI
   4.7 调试日志面板
5. 系统适配
   5.1 macOS 代理与钥匙串/信任
   5.2 Windows 代理与证书存储
6. 测试与验收
   6.1 自动化 L0/L1
   6.2 手工 L3 教务
   6.3 缺陷修复
7. 打包
   7.1 开发版运行说明
   7.2 安装包（后置可加深）
```

## 2. 里程碑

## 4. 风险登记册

| ID | 风险 | 概率 | 影响 | 缓解 | 应急 |
|---|---|---|---|---|---|
| R1 | 教务前端大量动态绝对 URL | 中 | 高 | 响应改写分层；先保导航 | 降级为「书签式 WebVPN URL」辅助 |
| R2 | Cookie 字段变更 | 中 | 高 | Session 探测集中 | 快速补丁 + 重登流程 |
| R3 | mitm 嵌入体积/签名 | 中 | 中 | 先开发者模式外置 mitm | 改用独立安装 mitm |
| R4 | macOS 权限弹窗劝退 | 中 | 中 | UX 引导文案 | 仅系统代理路径 |
| R5 | 学校政策限制自动化 | 低 | 高 | 私用、文档声明 | 停更/只保留手动转换 |
| R6 | 默认密钥轮换 | 低 | 中 | 配置可覆盖；预留读取 portal | 热更新 key |
