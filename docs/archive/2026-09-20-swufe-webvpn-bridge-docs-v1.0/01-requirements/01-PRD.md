# PRD — SWUFE WebVPN Bridge（第一期）

## 1. 文档信息

| 项 | 内容 |
|---|---|
| 产品 | SWUFE WebVPN Bridge |
| 版本 | Phase 1 / PRD 1.0 |
| 日期 | 2026-09-20 |
| 状态 | 已对齐 |

## 2. 背景与问题

西南财经大学校外访问校内 Web 资源依赖网瑞达 WebVPN（`webvpn.swufe.edu.cn`）。该产品为浏览器反向代理，不是系统级 VPN。用户无法让本机普通浏览器/应用以「访问真实内网主机名」的方式透明使用校内 HTTP/HTTPS 服务。

## 3. 产品目标

**让本机 HTTP/HTTPS 客户端在用户完成官方 WebVPN 登录后，对 allowlist 内主机自动经 WebVPN 访问。**

第一期成功标准：本机浏览器能打开并操作 `jwxt.swufe.edu.cn`（教务）页面。

## 4. 非目标

- SSH / 数据库 / SMB / 任意 TCP·UDP
- 替代学校 SSLVPN 或 TUN 级真 VPN（TUN 为后续阶段）
- 与 Clash 等系统代理链式共存
- 存储密码或绕过 MFA
- 班级批量分发与应用商店上架（第一期）

## 5. 用户与场景

| 用户 | 诉求 |
|---|---|
| 西财师生（开发者本人优先） | 校外用本机浏览器使用教务等站点 |
| 未来开源用户 | 可自建、可审计；文档说明证书风险 |

### 主路径

1. 打开 App → 安装 CA（首次）→ 登录 WebVPN（CAS/MFA）
2. 确认 allowlist（默认含教务）→ 打开开关
3. 用本机浏览器访问 `https://jwxt.swufe.edu.cn/...`
4. 流量经本地桥改写至 WebVPN 并带会话
5. 可正常浏览与操作页面

## 6. 功能需求摘要

| ID | 需求 |
|---|---|
| P1 | Electron：登录窗、开关、allowlist、状态、CA 安装/卸载、调试日志开关 |
| P2 | Session Broker：仅 Cookie；过期停桥+清代理+弹窗重登 |
| P3 | 流量：系统代理 + 进程 local 捕获 |
| P4 | 启动前检测系统代理，已占用则拒绝启动 |
| P5 | Allowlist 路由；默认 jwxt；可编辑；可选 `*.swufe.edu.cn` |
| P6 | WRD 请求改写 + 响应反向改写（Location/HTML·JS 绝对 URL/Cookie Domain） |
| P7 | 登录 WebView 不经过本桥（防环） |
| P8 | 调试日志：域名+是否改写成功；不记正文 |

## 7. 平台与发布

- 第一期：macOS、Windows
- 受众：私用；架构保持日后可开源
- 语言：中文界面优先

## 8. 成功指标

- 功能：验收清单全部通过（见测试计划）
- 体验：从「已登录」到「浏览器打开教务」≤ 3 次点击（不含 CAS 本身）
- 安全：无密码落盘；CA 可卸载；关闭后无残留系统代理

## 9. 里程碑（产品视角）

1. Codec 与单元验证（已完成原型）
2. mitm WRD addon + Cookie 联调
3. Electron 壳与系统代理/CA
4. 教务浏览器验收
5. 文档与开源准备（可选）

## 10. 风险（产品）

| 风险 | 影响 | 缓解 |
|---|---|---|
| 教务页大量绝对 URL/复杂前端 | 点击跳飞 | 响应改写必做；用例覆盖关键跳转 |
| 会话/Cookie 策略变化 | 断连 | 过期明确停桥；适配点集中在 Session Broker |
| 学校政策 | 合规争议 | 仅服务授权用户；文档声明官方通道与风险 |
| 与其它代理冲突 | 无法启动 | 拒绝启动并提示（已选策略） |
